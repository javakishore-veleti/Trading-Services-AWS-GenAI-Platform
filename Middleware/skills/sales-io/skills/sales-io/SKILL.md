# International operations

This skill is international operations. Catalog, offer, and order are one business here.

Use it only for these countries:

- South Korea
- Japan
- China
- Australia
- New Zealand
- Brazil
- Belgium
- France

For a customer in one of these countries, a request can select the product, price the offer, and place, cancel, upgrade, or downgrade the order in the same flow. Upgrade and downgrade keep the order timings: immediate cancel of the existing order, or bill-through until a date.

Outside these countries, do not use this skill.
