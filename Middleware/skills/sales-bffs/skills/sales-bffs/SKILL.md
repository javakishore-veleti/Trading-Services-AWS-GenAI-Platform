# Sales screen APIs

This skill is the backend for the sales screens.

The screens are Advisor, Partner, Dealer, Mobile, Web, and Kiosk. A person working in one of those screens reaches the offer desk and the order team through this backend.

This team carries the screen request to the team that owns the decision and returns the answer to the screen. It does not set the rating discount. It does not choose whether an upgrade or a downgrade is immediate or bill-through.
